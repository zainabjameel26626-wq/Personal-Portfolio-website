# Personal-Portfolio-website
# Zainab Jameel — Portfolio

Responsive portfolio built with HTML5, CSS3, Bootstrap 5.3 and Bootstrap Icons.

## Structure
```
index.html
css/style.css
js/script.js
images/Picture1.jpg          profile photo
images/projects/             project screenshots (see below)
videos/                      project demo videos (see below)
```

## Adding project images and videos
| Project | Image | Video |
|---|---|---|
| Student Quiz Application | `images/projects/student-quiz-app.jpg` | `videos/student-quiz-app.mp4` |
| Shortest Path Visualizer | `images/projects/shortest-path-visualizer.jpg` | `videos/shortest-path-visualizer.mp4` |

Videos can be `.mp4` (H.264 + AAC, recommended), `.webm` or `.mov`. If no file loads, the modal shows the expected file name.

## Bootstrap components used
Navbar · Collapse · Container / Grid · Buttons · Cards · Badges · Modal · Forms (+ validation) · Alerts · Utilities

## Custom CSS
Design tokens with light and dark themes · gradient hero, buttons and accents · card hover lift · project image zoom · smooth scrolling · back-to-top button · reduced-motion support
