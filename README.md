# Zainab Jameel: Portfolio

A responsive personal portfolio website built with HTML5, CSS3, Bootstrap 5.3 and Bootstrap Icons.

**Live demo:** https://zainabjameel26626-wq.github.io/Personal-Portfolio-website/

## Features
- Responsive layout that works on phones, tablets and desktops
- Light and dark themes
- Project cards with a modal that shows an image and a demo video
- Contact form with validation
- Smooth scrolling and a back-to-top button
- Reduced-motion support

## Technologies
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- JavaScript

## How to run
1. Download or clone this repository:
   ```bash
   git clone https://github.com/zainabjameel26626-wq/Personal-Portfolio-website.git
   ```
2. Open `index.html` in your browser. No installation or build step is needed.

## Customisation

### Adding project images and videos
| Project | Image | Video |
|---|---|---|
| Student Quiz Application | `images/projects/student-quiz-app.jpg` | `videos/student-quiz-app.mp4` |
| Shortest Path Visualizer | `images/projects/shortest-path-visualizer.jpg` | `videos/shortest-path-visualizer.mp4` |

Videos can be `.mp4` (H.264 + AAC, recommended), `.webm` or `.mov`. If no file loads, the modal shows the expected file name.
